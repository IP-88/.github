## 什么是印度尼西亚住宅代理

印度尼西亚住宅代理，也就是Indonesia Residential Proxy，主要指通过印度尼西亚住宅或本地ISP网络提供互联网出口的代理服务。

基本结构可以理解为：

```text id="idproxy01"
用户设备
    ↓
代理服务
    ↓
印度尼西亚住宅网络
    ↓
Indonesia IP
    ↓
目标网站
```

与普通印尼VPS相比，住宅代理更关注IP的住宅网络属性。

一些服务商公开的印尼住宅资源来自本地运营商和消费者网络。例如Shifter目前公开雅加达住宅IP来自Telkom IndiHome、Biznet、First Media、MyRepublic、CBN以及部分移动运营商。

ZapIP也公开提供来自Telkomsel、IndiHome、Indosat、XL Axiata和Biznet等网络的印尼住宅IP，并支持城市和ASN定向。

**ISP注册属性不等于真实家庭宽带线路。**


这种产品通常按照GB收费，更适合需要大量访问和IP轮换的场景。

## 印尼静态住宅IP和动态住宅IP有什么区别

两类产品最大的区别是IP是否需要长期固定。

| 对比项目  | 静态住宅IP | 动态住宅IP    |
| ----- | ------ | --------- |
| IP变化  | 通常固定   | 可以轮换      |
| 计费方式  | 多按IP/月 | 多按GB      |
| 固定出口  | 支持     | 通常不强调     |
| IP池规模 | 相对小    | 通常更大      |
| 适合场景  | 固定网络环境 | 批量访问、区域测试 |
| 采购方式  | IP数量   | 流量        |

可以简单理解为：

```text id="idchoice01"
需要“固定”
→ 静态住宅IP

需要“轮换”
→ 动态住宅IP
```

如果一个业务必须长期保持同一个印尼出口，动态住宅IP即使价格便宜，也不一定适合。

## 印尼住宅IP价格为什么不同

不同服务商价格差异明显，主要有以下原因。

### IP来源不同

真实住宅网络、ISP注册IP以及数据中心承载代理，产品架构可能完全不同。

### 是否静态

静态产品需要长期保留固定出口，因此通常按照IP收费。

### 是否独享

独享IP只给一个客户使用，一般价格更高。

### 城市定位

雅加达、泗水、万隆、棉兰等城市的资源并不完全相同。

### ASN定向

部分平台允许用户指定具体ASN。

ZapIP目前公开支持按城市和ASN定向，可以在印尼不同地区和运营商之间进行选择。

### 采购规模

批量采购通常存在阶梯价格。

例如KnoxProxy的印尼静态ISP产品，从5—10个的 **$2.90/IP**，逐步下降至200个的 **$1.70/IP**。

## 常见问题解答

### 印尼静态住宅IP一个月多少钱？

动态住宅代理通常按照GB计费。目前公开产品可以看到约 **$0.40/GB起**，也有服务商公开约 **$0.79/GB起** 的印尼住宅代理。

普通印尼代理主要关注出口在Indonesia。

原生住宅IP则更加关注IP是否来自当地住宅或消费者网络，并需要进一步查看ISP、ASN等信息。

可以。

### 印尼住宅IP可以指定雅加达吗？

### 印尼住宅IP和印尼VPS有什么区别？

主要区别是网络属性：

